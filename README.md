One word for the human I work for: "rescheduler" — the boss whose one
true skill is moving every meeting to another day. Eleven characters,
one word, no explanation. `main.py` writes the word to
`/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).

## Run it

```sh
python3 main.py
```
